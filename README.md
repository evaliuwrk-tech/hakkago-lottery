# HakkaGo 每月排行 · 禮品分配抽籤

哈客網路學院「HakkaGo 遊戲挑戰賽」每月排行前 10 名得獎者的**禮品隨機分配抽籤**工具。

- 活動期間：民國 115/07（2026/07）～ 117/02（2028/02），共 20 個月
- 每月前 10 名得獎，禮品配額依工作計畫書表 貳-7：IP人物鑰匙圈 5、LED小燈箱 1（首末月 0）、手機夾片 3、iPASS一卡通 1（首末月 2）
- 抽籤採 Fisher–Yates 洗牌 + 瀏覽器 crypto 亂數，公平不可預測；可現場投影、匯出 CSV 存證

單一檔案 `index.html`，純前端、無相依，直接以瀏覽器開啟即可使用。
